# Contributing

All work enters through a branch and pull request. Do not push implementation or
data directly to the protected default branch.

## Required handoff

Every pull request must state:

- scope and non-goals;
- files added, changed, and generated;
- evidence basis for new metadata or claims;
- tests and hostile cases run;
- public-exposure scan result;
- rebuild instructions;
- files that are temporary or safe to delete.

## Agent rules

- Read `REPO_BOUNDARY.md` before writing.
- Do not request, copy, or infer access to the private archive.
- Do not manufacture demo facts from private records.
- Use `unknown` or `needs_review` when evidence is insufficient.
- Do not silently substitute a visually similar asset.
- Stop if a task requires private data to enter this repository.

Only reviewed, public-safe, reproducible work is eligible to merge.
